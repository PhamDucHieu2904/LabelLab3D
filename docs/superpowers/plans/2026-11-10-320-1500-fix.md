# 320ml framing and PET 1.5L replacement plan

## Intent
Make the 320ml full-label variant display with the same size as index 0, and replace PET 1.5L with the supplied repaired GLB.

## Root cause
Measured 320ml shells already match within compression precision. The rotated Nata mesh inflates transformed local AABBs: index 1 runtime bounds were 107.611 x 158.952 x 90.961 mm while actual geometry is 64.293 x 149.807 x 63.889 mm. The inflated box drives animated camera fit and shrinks the bottle on screen. Index 1 also opted into a different authored camera focus (`cameraFraming: bounds`).
The current PET 1.5L manifest used an older 41,756-triangle source. The supplied repaired file retains compatible semantics and has 156,300 triangles.

## Implementation
Use shared `measureProductBounds` with precise vertex bounds for viewer/mockup loading, centered bounds, upright refresh and thumbnails. Let index 1 use the same authored camera focus as index 0. Preserve actual model geometry and label UVs. Reimport only pet-1500-juice through the existing Draco adapter, refresh manifest and native poster.

## Verification
- Product bounds regression covers rotated sparse geometry, actual decoded 320ml heights, inclusion width, and animated camera fit at four aspects.
- Asset test pins the repaired PET 1.5L source hash and all 156,300 triangles.
- Headless 1.5L direct/pooled/front/above/under renders report no WebGL or shader errors.

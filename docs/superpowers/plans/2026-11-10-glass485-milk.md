# Glass 485 ml Milk Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Publish the supplied 485 ml glass bottle as a Draco-compressed Milk model with the same clear Base treatment and hollow Neck optics used by the existing Glass 300/290 Milk models.

**Architecture:** Adapt the source GLB without simplifying or changing its buffers. Split the source Body mesh's Body, Neck, and GlassBase material primitives into separate nodes so the existing calibrated Base and Neck runtime paths receive the correct geometry; rename only semantic materials/nodes, add the existing glass-300 profile metadata, wrap the scene in the established 0.1 metre conversion node, and compress with the existing Draco encoder. Register the asset as a Milk glass model/family entry with a generated poster and explicit manifest.

**Tech Stack:** glTF/GLB JSON adapter, `draco3dgltf`, Three.js runtime materials, Node test runner, TypeScript catalog/preferences.

**Spec:** User request in chat: add `485ml bottle - Original Label UV preserved - Quads.glb`, use Milk, process Base and Neck like Glass 300/290 Milk, and add it to the project.

## Global Constraints

- Preserve all source triangles and `TEXCOORD_0` UVs; no simplification.
- Keep Draco position/UV error within the repository's existing limits.
- Keep the supplied model's label UV orientation and physical silhouette.
- Use the existing Milk reservoir shader and hollow Neck tracer; do not create a parallel optical implementation.
- Do not use desktop UI or mouse automation.

## Review Focus

- Source Body contains three material primitives; Base and Neck must not receive the whole Body bounds.
- The Milk water must remain `FrontSide` and use the stable cream reservoir output.
- The Neck trace must select only Neck geometry while retaining the authored wall.
- The model must fit camera bounds and its label/cap/material slots must be independently editable.
- Asset hash, manifest, poster, catalog and persisted Milk defaults must all agree.

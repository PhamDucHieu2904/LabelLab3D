# PP 500ml Draco import plan

## Intent
Add both supplied PP 500ml GLBs to the web model library as two variants in one 500 ml PP family, with Draco-compressed assets that preserve authored geometry and UVs.

## Approach
Reuse the existing `import-bottle-batch.cjs` adapter and PP opaque material contract. Add two entries, publish manifests/assets, generate native posters, expose both variants through `lib/labellab/bottle-batch.ts`, and extend asset/geometry tests. This fits the existing batch pipeline and avoids a new importer or runtime shader path.

## Calls
- IDs: `pp-500` for `500 ml pp bottle web.glb`, and `pp-500-2` for `500mlPPbottel2 web.glb`.
- Both are opaque PP bottles with no liquid slot; labels are editable through the existing PP catalog contract.
- Create one `pp-500` family with `standard` and `variant-2` entries, preserving source transforms and UV sets.
- Draco uses the existing precision settings and no simplification; each output must remain below 1 MB.

## Verification
Add failing tests for both published assets, catalog variants, and preference defaults; then run the focused tests, asset verification, typecheck, lint, full test suite, and production build.

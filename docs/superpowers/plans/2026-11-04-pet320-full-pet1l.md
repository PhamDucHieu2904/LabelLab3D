# PET 320 full label and PET 1L Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task by task.

**Goal:** Deliver compressed Draco web models with usable label/material controls.
**Architecture:** A focused Draco import/validation helper encodes each primitive while retaining the source scene; import adapters set metre units and existing PET optical profiles. Catalog and preferences register two new persistent model IDs.
**Tech Stack:** Node, draco3dgltf, Three.js, Next.js/TypeScript.
**Spec:** ../specs/2026-11-04-pet320-full-pet1l-design.md

## Global Constraints

- Preserve source files, all triangles/UV seams/materials and old model IDs.
- PET320 <=1,240,124 bytes; PET1L <1,000,000 bytes; no simplification.
- Position <=0.01mm, UV <=0.5px at 4K, normal <=0.1 degrees.
- Work in the existing checkout to retain the uncommitted material/catalog baseline needed by this task; no commits, branch operations or publishing.

## Review Focus

- Encoder reorders vertices/faces: compare decoded triangle corners, not index numbers.
- Source nonuniform transforms: measure position/normal errors in world metres.
- Shared attribute accessors: preserve each primitive's semantic binding.
- Long labels/caps: remain opaque and independent after artwork upload/remove.
- Old Nata selection: model ID, GLB hash and saved preferences remain valid.
